# gram-ontology

A planned extension to the [`gram` CLI](https://github.com/gram-data/tree-sitter-gram) for working with `*.ontology.gram` files: strict syntactic and semantic checks over valid gram, and export of the ontology as JSON.

Early stage. See [`notes/extension-design.md`](notes/extension-design.md) for the design so far and [`notes/structural-ontology-notes.md`](notes/structural-ontology-notes.md) for the background that informs the model.
